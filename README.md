# Airbnb Data Analysis

## Project Overview
An exploratory data analysis (EDA) project that examines Airbnb listing data to understand pricing patterns, room-type distribution, and neighbourhood-level differences.

## Objectives
- Clean and prepare Airbnb listing data using Python.
- Identify and handle duplicate records, missing values, and invalid entries.
- Analyze listing prices across room types and neighbourhood groups.
- Visualize key patterns using statistical charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Dataset
The project uses the Airbnb Open Data Excel dataset included in this repository.

## Key Findings
- Analyzed **98,361 listings** in the final analysis dataset.
- The average recorded listing price was **$625.67**, with a median of **$625.00**.
- Entire homes/apartments were the most common room type, with 51,384 listings.
- Hotel rooms had the highest average recorded price among room types at $661.41.
- Manhattan and Brooklyn had the largest numbers of listings in the analysis dataset.

*Note: These findings describe the provided dataset and should not be interpreted as current Airbnb market prices.*
